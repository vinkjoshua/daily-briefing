# Daily Briefing v1.1 implementation plan

Goal: implement the approved smaller onboarding/tuning flow with existing Python code, standard libraries and gh.
Spec: docs/plans/2026-10-06-v1.1-onboarding.md

## Global Constraints

Ponytail full; Python >=3.11; retain argparse, uv, pytest, Ruff and Hatch. No unrelated refactors or new UI frameworks. Codex 0.160.0; gh 2.102.0. Supported platforms: macOS/Linux/WSL, x86-64/ARM64. Secrets never enter command arguments/logs/tracked files. Preserve current v1 engine commands and encryption format. No external changes, pushes or releases during implementation. TDD: record real expected red, implement minimum, focused green, full suite before handoff. No subagents from workers. Commit only your own task changes. Use git -c user.name=Codex -c user.email=codex@users.noreply.github.com commit if local identity is absent.

## Review focus

Cancellation must preserve accepted personalization. A repository collision must not be adopted as an interrupted setup. Preview and publishing must reject symlink paths. Secret-bearing outgoing commits must be rejected even if later commits delete the path. Ambiguous push/dispatch outcomes must not trigger a blind retry.

### Task 1: tool bootstrap, GitHub command boundary and packaging

Read the Global Constraints copied into the dispatch. Own `bootstrap.py`, `github.py`, their tests, and initial package resource configuration. Do not implement wizard/preview/publish or modify their command registration.

Interfaces:
- `bootstrap.ensure_tool(name: str) -> Path`, accepting codex or gh; `BootstrapError` for actionable failures.
- `github.run_gh(binary: Path, args: list[str], *, input_text: str | None = None, capture: bool = True, check: bool = True) -> subprocess.CompletedProcess[str]`.
- `github.git(root: Path, *args: str, gh_bin: Path | None = None, check: bool = True) -> subprocess.CompletedProcess[str]`.
- `github.CommandError` contains safe diagnostics. These helpers are thin subprocess boundaries, not an API/transport framework. run_gh does not echo stdin. git sets hooksPath=/dev/null and disables terminal credential prompting for noninteractive operations. With gh_bin set, use gh auth git-credential only for this command and HTTPS github.com; do not alter user/global git config.

Requirements: use pathlib/platform/shutil/urllib/hashlib/tarfile/zipfile/tempfile only. Official pinned assets and SHA256 values are in the workspace release-assets.json provided by controller. Choose macOS amd64/arm64 gh zip and Linux amd64/arm64 gh tar.gz; Codex complete codex-package archives, not the single executable. Preserve relative package contents/companion executables and expose proper executable entry. Detect platform before network; reuse exact matching PATH binaries. Versioned private cache in user cache location; tests redirect cache with XDG_CACHE_HOME. Download to temporary sibling, hash before extraction, reject traversal/unsafe link members, atomic rename only after executable check. Canceled or corrupt installs must not be reused. Do not launch an installer or require sudo/Node. Support paths with spaces. Minimal clear progress and actionable download errors.

Package canonical `template/` as `daily_briefing/starter` with Hatch force-include; keep source canonical. Promote existing PyYAML from dev to runtime through uv. Keep existing tooling and package version for now. Add installed-resource test/build smoke as feasible offline.

TDD sequence: failing cache/download/archive/command-boundary tests; implement minimal helpers; focused tests; full suite, Ruff on changed files; commit. Report exact red/green command outputs and public interfaces. Use monkeypatched network/subprocess boundaries but real archive fixtures and filesystem operations; don't mock away security assertions.

### Task 4: reviewed publication with real Git recovery

Own publish.py, its tests, publish CLI registration and publication docs. Consume Task 1 GitHub helpers and Task 3 workflow reader plus existing validation.

Interface `publish.publish(root: Path, *, run: bool = False) -> int`. Default current instance; recognize v1 layout plus single action workflow and valid personal GitHub origin. Validate local profile/sections and literal workflow fields. Check remote repo private and authenticated owner. Support HTTPS and SSH origin parsing but authenticated operations via a clean HTTPS URL with scoped gh helper; preserve original origin.

Fetch actual default branch, allow only its matching local branch, reject detached/custom histories with clear recovery. Ensure no unreviewed index state/unrelated dirty paths is destroyed. Allow interests.md, sections/*.md, state/*.md, .github/workflows/briefing.yml, briefing launcher, README.md, AGENTS.md, CLAUDE.md and .gitignore; reject symlinks and other file types; exclude preview.html/briefings/.briefing and all credentials. Inspect each outgoing commit's touched paths, not merely aggregate diff, including paths later deleted; reject disallowed history. Review all outgoing commits plus allowed working diffs including new files; confirm before creating commit/pushing.

Use ordinary fetch/rebase/push for bot changes. Rebase only when clean after committing reviewed changes; on conflict abort that rebase and retain the user's local commit/work, report exact next steps. Never force-push, auto-stash unrelated work, reset user's index or delete work. If remote advances again, fail with safe retry instructions. Revalidate/review changed resulting content before push when needed. Local commit name uses existing repo identity, else locally derived gh identity (no global changes). `--run` only after successful/noop publication; ordinary run respects daily guard. Ambiguous dispatch reports uncertainty without blind retry. Public or mismatched repo and unsupported histories stop before local mutation.

Tests first using real temporary repos + bare remote and mocked gh only: reviewed selected commit/push, rejected paths anywhere in outgoing history, index preservation, rejection/cancellation, bot fast-forward/nonconflicting rebase, conflict preserves local commit, push rejection and retry, gh credential scoping, optional dispatch.
